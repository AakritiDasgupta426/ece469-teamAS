The purpose of having an individual handler function for each exception is to allow the kernel to identify which trap occured and ensure that the trap information is pushed onto the stack in a format. By using seperate handlers, the system can push the trap number and add a dummy error code when necessary so that all traps have the same stack layout before transferring control to _alltraps routine. Allowing the kernel to handle different exceptions in a uniform way.
